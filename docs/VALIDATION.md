# v1.5.2 验证记录

## 本版检查

- 现场评分：79.99 进入弃置，80 和 80.01 保留；理论上限很高不能单独保留平均潜力低于 80 的胚子。+15 即使低分也跳过。
- 设置迁移：旧版 70/85 及额外保留设置不会覆盖本版平均潜力 80 规则，目标角色范围保留。
- 低分锁定件：评分明确要求解锁，且服务和执行计划允许后才解锁；解锁后重新识别属性和锁定状态，再标记弃置。
- 真实执行函数使用不含系统调用的输入替身：确认先解锁一次，再标记一次。解锁未生效、解锁后属性变化或未授权解锁时不点弃置。已装备、未知锁定状态、+15、离开背包和取消均受保护；弃置结果未确认时不重复点击。预览不执行输入。
- 请求交互：前后核验保留潜力和解锁标志，拒绝过期回应、达到 80 或 +15 的弃置指令。部分或未识别背包不能授权强化。
- 主属性独立区域：通过两张既有游戏画面的中文标签识别回归。原始画面、背包和玩家记录不在仓库中。
- 浏览器界面：主按钮实际标记，只读入口独立；旧设置迁移、锁定低分件解锁决策及后续核验、+15 跳过、停止后的迟到评分抑制、三种排序及窄窗口布局。
- 背景：59 张官网图片逐文件校验，后续女性角色名单检查；本地图片路由与格式检查，非法名称返回 404。默认不透明度 82%，选择与清晰度保存，手动换图与搜索，50 次选择不连续重复。
- 离线识别：合成数字、灰色预览词条与既有游戏样本回归。浏览器测试无外部请求，游戏操作接口被模拟层拦截。

## 实机边界

这些检查没有解锁、标记、强化或分解真实游戏中的遗器。解锁、弃置点击、完整背包遍历和强化仍未完成真实游戏端到端验证，本版保留测试版标记。

强化沿用逐次 +3、未满级平均潜力 80、满级当前分 80 的策略，限制经验材料与四星及以下遗器。材料弹窗、页面返回和新词条读取仍需实机验证。

- 角色图库：59 张图片本地加载，搜索、选图、切换、清晰度调节及重开后保存。
