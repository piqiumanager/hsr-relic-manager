# v1.5.5 验证记录

验证日期：2026-11-26。

## 已通过

- 完整 3000 件混合模型：包括相同词条的重复遗器、已锁定低分、已弃置、已装备、四星和无效数字。1950 件应标记的全部标记，900 件应解锁的全部解锁；未重复点击，末行三格也完整遍历。无效识别使状态保持部分完成。
- 连续强化与重排模型：三条高分路径各强化五档，三条掉分路径均在 +6 弃置。高潜力锁定胚子会先解锁。每档消耗低星材料并重新排序，最终未漏项，已经弃置的不会被反向取消。
- +0/+3/+6/+9/+12/+15 各自覆盖锁定和未锁定低分，共十二种执行组合。高分锁定件、解锁后取消、状态不明和未完成报告也通过执行链，合计 68 项断言。
- 78 项数字识别生命周期断言：运行退出、卡死、设置参数时卡死、初始化失败、初始化迟到、低置信度、取消和重试。终止后不会复用旧组件，迟到初始化不会覆盖新组件。
- 浏览器新增挂起识别时停止、停止接口失败后重试、组件故障转停止、材料不足未完成列表和重试至 +15。全部游戏 API 被拦截。

- 新增 1,024 件合法随机遗器，覆盖初始三/四词条、+0 至 +15、低中高档位；连同异常次数和主属性值，共 1,063 项评分/档位检查。
- 42 项异常输入与状态检查：NaN、无穷、空值、字符串与布尔值不能冒充属性或评分；另一件遗器、另一帧图片、改变的词条类别不能冒充本次回包；缺失或跨过 80 的评分下界不能强化。
- 新增评分恰好送达时停止、空背包、最后一条记录未保存时的快照完整性，以及进程退出但状态缺少 message 字段的回归。
- 无界面浏览器验证评分上下界传递，终止状态即使附带旧 request 也不会继续评分或发送操作。

- 23 组基础离线套件：评分、导入、80 分边界、+15 当前分、锁定与装备保护、计划校验、API/文件通信、执行函数、材料规则、快照、背景、离线 OCR 资源、简体中文 OCR。
- 完整离线处理链 68 项断言：真实 Process-LiveRecord、评分请求文件、JavaScript Fribbels 评分、Accept-LiveDecision、解锁/弃置执行、Generic.List 快照及异常处理。仅屏幕、点击和材料消耗替换为不含系统输入的模拟层。
- 高分样本从 +0 依次通过 +3/+6/+9/+12/+15；低分样本在 +6 被重新评分为低分，标记一次后不继续强化。
- 锁定低分样本先解锁一次，再弃置一次，核验通过才增加成功数。未装备低分 +15 标记；已装备低分 +15 保留并输出提醒。
- 解锁无效、弃置无效、属性变化、过期回应、离开背包、取消、错误材料和强化后身份不符均不重复操作、不虚增成功。
- 完整模拟遍历中加入背包重排和材料消耗，重新统计并完成稳定遍历；已标记遗器不会被反向取消，高分 +15 不再消耗材料。
- 快照保存故意失败时，最终状态仍写入原始错误，不能掩盖故障或滞留 awaitingScore。
- 锁定控件另用本机已保存的真实按钮小图复核。玩家图片和账号记录未纳入仓库。
- 两组浏览器集成：无需重登或完整快照的启动、逐档重新评分、同件只保留一行、已装备提醒、迟到评分停止、数字 OCR、明细排序、59 张本地图片及窄窗口布局。所有游戏操作 API 被拦截；外部请求为零。
- 合成简体中文标签 OCR 与固定主属性回退 21 项检查；头部/手部按游戏固定主属性处理，其他部位无法确定时不猜主属性。

## 尚未验证

本轮没有向游戏发送输入，没有解锁、标记、强化或分解真实遗器。真实游戏中的按钮点击、完整背包遍历、材料菜单、强化弹窗与返回流程仍需实机复测。离线通过不能替代实机验收，也不代表完全无 BUG。

## 复现

准备固定 OCR 资源后运行 node scripts/run-offline-tests.cjs；完整 3000 件模拟可加 --stress；安装 Windows 简体中文 OCR 后可加 --ocr。浏览器测试需要独立 DataRoot 的 server.ps1、Playwright 与 Chrome，运行 scripts/test-live-ui.cjs 和 scripts/test-upgrade-ui.cjs。所有测试均不启动真实游戏执行器。
