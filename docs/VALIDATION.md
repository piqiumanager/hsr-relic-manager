# 独立验证记录

版本：v1.2.0。记录日期：2026-11-23。

本记录与使用说明分开保存，供维护与审阅。

已完成的本地验证：

- 119 项评分与导入断言，包括五星角色范围、当前分、强化潜力、缺失字段保护和 3000 件背包处理。
- 14 项自动标记清单断言，包括锁定/装备保护、已弃置跳过、隐藏小数碰撞、低星视觉碰撞和新快照要求。
- 19 项匹配、几何、图标状态与原生模块编译断言。
- Windows 内置中文 OCR 的合成图片识别。
- 10 项服务端快照核对断言。
- 浏览器界面的导入、筛选、导出、会话恢复、标记入口和本机 API 测试。
- 发布包完整性、PowerShell 语法，以及从随包源码重新生成界面的一致性检查。

自动标记界面测试使用模拟服务响应，没有向游戏发送输入。合成图片 OCR 测试没有使用实际游戏截图。

尚未完成的验证：实际游戏界面校准、真实背包遍历和端到端弃置标记。首次使用应先做“仅识别预览”，遇到未识别、布局变化或不能确认标记的情况应停止并保留日志排查。

EXE 升级验证：

- 单文件约 4 MB，内置 Reliquary 官方 EXE，SHA256 与官方发布元数据一致。
- 在正常 Windows 环境启动自解压 EXE，创建内嵌 WebView2 桌面窗口，验证本机 API 与 112 件示例评分，退出码 0。
- 单独验证“一键整理”的模拟读取、等待打开背包、标记调用及读取失败后禁止使用旧结果，共 11 项检查。
- 下载 ZIP 目录只有 EXE 与说明两个文件。

受限进程沙箱中的 WebView2 本机网络导航超时；相同 EXE 在正常 Windows 环境通过。上述测试均未读取真实游戏账号或向游戏发送输入。
