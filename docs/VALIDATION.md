# v1.5.6 验证记录

日期：2026-11-26。

## 离线范围

- 32 组基础套件，包括既有评分、数字识别、+3 强化、解锁弃置、文件通信与快照回归。
- 112 项角色解析：已有详情的等级证据、中文角色名、命途、主角昵称、UID、跨列菜单 OCR、未知角色和无效名单。
- 24 项顶栏几何检查；7 项遍历检查覆盖重叠、单页、失败点击、拖动过头与停止。
- 15 项名单持久化与 API 检查；16 项评分限定检查。未拥有角色的高分不能挽救或触发强化，旧文件和旧设置不能扩张角色范围。
- 通用高速 12 项评分与保护检查，以及 38 项执行校验。包括风套速度鞋、副速度 10、未满级强化机会、普通低速件继续清理、错误弃置指令被拒绝、强化后保护停止和未拥有评分角色被拒绝。
- Windows 简体中文 OCR 使用合成图检查角色名、命途、等级、UID 和手机菜单跨列文字。未使用玩家画面。
- 3 组无界面浏览器：首次读取、名单栏、清理与强化、刷新中断、切换账号、排序、随机背景、停止重试与窄窗口。所有游戏 API 均被拦截。
- 完整 3000 件模型继续校验 1950 件应标记、900 件应解锁、同词条重复件、末行、材料消耗、背包重排和先清理再强化，48 项断言。

## 实机范围

本轮没有启动游戏执行器或向游戏发送输入。真实角色顶栏圆框检测、手机菜单、UID、角色命名变体、解锁弃置、强化返回与材料菜单仍待游戏内验收。离线通过不能代表完全无 BUG。

原有锁定控件图像曾以本机留存的局部图离线核对；这些账号图片和数据没有进入仓库。发布包内置源码、9 个 OCR 资源及 59 张官网角色立绘均核对校验值。
