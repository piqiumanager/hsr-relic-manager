# v1.4 验证范围

## 已验证

- 评分核心与潜力算法、主属性导入、弃置计划与保护条件、快照验证、固定布局和键盘导航沿用回归测试。
- 强化策略：每次 +3 至 +15，未满级平均潜力 80、满级当前分 80，低分停止强化并仅标弃置。
- 强化重新评分：使用新 OCR 属性，根据显示取整重建隐藏小数区间；校验主属性与等级，拒绝缺失词条或不符合游戏档位的数值。
- 真实执行函数在模拟屏幕接口下完成 3/6/9/12/15 五步，在低分节点停止并标弃置。确认函数在 +15 误置入、五星材料范围时拒绝点击，准备函数在材料槽非空时拒绝自动添加；预览只准备、取消，无强化确认。
- 后端验证强化计划、禁止并发、匹配评分请求与响应、在已强化或标弃置后失效旧快照。测试不启动游戏执行进程。
- Windows 简体中文 OCR 识别属性行及字词坐标；原生图像辅助识别八个空材料槽。
- UI 集成测试模拟背包读取与游戏状态，覆盖模式切换、首次 +3、收到新词条后重新评分、结束后清除旧快照，以及简洁界面弹窗与窄窗口布局，以及六张官方立绘的离线显示和启动轮换。测试不操作游戏。
- 单文件 EXE 用独立数据目录验证嵌入 WebView2、版本接口、示例背包评分及内置 Reliquary，不读取玩家背包或发送游戏输入。

## 实机边界

当前没有运行中的游戏可验证。本版已包含实际按键、OCR 控件定位、材料规则选择、确认强化、新词条回读和弃置执行模块；尚未完成真实游戏端到端验证。当前简体中文控件别名、区域和空槽识别可能需要结合实机画面调整。

材料与目标检查无法通过时停止，不尝试猜测点击。游戏输入、确认强化和材料消耗没有在测试中发生；模拟流程通过不能表述为游戏实测通过。

v1.3 的评分导入修复已用本机实际背包回归。本版未改动该导入核心，玩家原始账号文件不在仓库或发布包中。
