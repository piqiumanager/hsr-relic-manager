# v1.5 验证记录

## 已通过

- 既有游戏画面只读回归：1920×1080 原始像素的背包总数、遗器单件与套装、等级、主属性和四条副属性。离线数字模型读取与画面一致；已装备样本被保护。玩家原始截图和背包不在仓库中。
- 评分及导入核心：沿用完整评分回归；角色列表空值不会使导入崩溃。现场评分检查隐藏小数上下界，保护锁定、装备和状态不明的遗器。
- 真实标记函数使用无系统调用的模拟输入层测试：确认标记只点击一次；锁定、装备、属性变化、离开背包和取消时不点击；点击后身份变化或红色标记未出现时停止，不重复点击。预览不应用标记。
- 现场评分 IPC：请求与响应匹配，拒绝过期回复；直接启动不需要登录快照，读取模式传递预览标记，验证程序传递三件上限。
- 快照：部分读取不授权强化，完整读取持久化；缺少已拥有角色信息时，在启动任务前提示更换评分范围。
- 视觉保护：装备边框的有、无、不确定三种状态；点击前后重新识别并核对等级、主副属性，图像细微变化不会误判为属性变化。真实已装备截图也通过边框保护回归。
- 浏览器界面：无新登录快照时开始按钮可用；低分、高分、保护和异常属性的响应；读取模式只预览；评分中停止不再提交迟到决策；三项排序及升降序；窄窗口按钮完整可见。
- 离线识别：合成数字图与既有游戏裁剪样本回归。浏览器测试记录未出现外部网络请求，所有游戏操作 API 均被模拟层拦截。
- 打包依赖固定版本并核对 SHA256；离线模型和 WASM 由构建准备脚本下载后校验，随发布 EXE 内置。
- 打包后的 DesktopHost 在不激活窗口的离屏模式通过 WebView2 自测：本地服务、112 件示例评分、六张内置背景、按钮布局和离线数字识别。测试使用普通权限组件入口，没有启动需要管理员确认的发布 EXE。

## 实机边界

只读画面回归没有标记、强化或分解遗器。此前导航测试未出现预期移动，并确认游戏为管理员进程；本版将启动权限统一到管理员、改进焦点交接和等待，并在失焦后停止。不能把这些代码改动与模拟测试表述为权限问题已在实际标记流程中完全解决。

当前没有可供继续测试的游戏环境。真实游戏的完整背包遍历、实际弃置点击和强化全流程仍未完成端到端验证。本次发布保留测试版标记；锁定、装备、身份和结果检查不确定时停止或保护。

强化策略及模拟执行测试沿用 v1.4：每次 +3、未满级平均潜力 80、满级当前分 80，限制经验材料与四星及以下遗器。强化的材料弹窗、页面返回和新词条读取仍需实机验证。
