v1.4.0 测试版：自动强化执行模块与简洁界面。

下载 ZIP，只有 EXE 和简体中文说明。支持 Windows 10/11 64 位、游戏简体中文、PC 键鼠模式、1920×1080 客户区。

新增“强化”模式：查找高潜力胚子，每次 +3，读取新词条并重新评分。未满级平均满级潜力 ≥80 继续，满级当前分 ≥80 保留；低分只标记弃置，分解仍由玩家确认。+0 先试到 +3。

允许经验材料与四星及以下遗器。执行前核对空材料槽，确认材料范围和下一档等级。可先用“仅预览”验证进入强化页、准备材料、退出的流程，不确认强化。F8 停止。

白底蓝色，参考 MAA 的任务列表布局。六位女性角色立绘来自星穹铁道官网，以淡色背景显示，每次打开更换且不重复上一张，离线可用。保留 v1.3 的主属性评分修复和免手动校准布局。

强化代码、UI 回传、OCR 和 EXE 启动已测试；真实游戏端到端操作尚未实测。遇到识别不确定会停止。请以识别预览核对当前游戏界面，任务截图与日志留在本机数据目录。
