下载 **hsr-relic-manager-v1.2.0-windows.zip**，解压后只有 **星铁遗器整理助手.exe** 和 **使用说明.txt**。双击 EXE 即可打开桌面界面。

- 内置 Reliquary Archiver v0.20.0 PktMon 读取组件、Fribbels 评分核心和五星角色资料，不需要 Python、Node 或另下读取工具。
- “一键整理”串起读取、评分和游戏内标记的引导流程。首次需要按截图校准；读取完成后需手动打开遗器背包，再点“继续标记”。
- 默认仅保留极高分与高潜力遗器，已强化和未强化一起筛选。
- 跳过锁定、装备、已弃置和有识别歧义的遗器。只打弃置标记，分解由你在游戏中确认。F8 可停止。

支持 Windows 10/11 64 位、本地中文客户端。界面使用系统 WebView2 Runtime，缺少时会提供微软安装入口。

**这是实验版：已通过本地评分、匹配、OCR、界面和 EXE 启动测试，尚未完成真实游戏全流程验证。首次先运行“仅识别预览”，检查后再标记。**

校验值见随发布提供的 SHA256SUMS.txt。完整源码、依赖许可和构建脚本均在仓库中。
