v1.5.4 · 异常识别与停止流程修复，继续作为待游戏复测的测试版。

- 修复副属性分别合法但总强化次数超过等级限制时仍被评分的问题。
- 修复异常主属性值及非有限数值可能穿过校验的问题。
- 评分回包必须对应当前遗器，数字识别回包必须匹配当前画面指纹和属性类别。
- 强化执行同时校验平均潜力下界达到 80，缺失或错误区间不允许消耗材料。
- 评分已返回时仍检查停止信号；停止前未保存全部记录的快照保持部分背包状态。
- 进程退出后清除过期评分请求；状态缺少 message 字段时也能显示真实错误。

22 组离线套件与 2 组无界面浏览器集成通过。新增 1,024 件合法随机遗器、共 1,062 项评分/次数断言，39 项异常身份与回包断言，完整模拟执行链为 38 项断言。

本轮未向游戏发送输入，没有进行真实解锁、弃置或材料消耗。本版不提供完全无 BUG 承诺。分解仍由玩家确认。
