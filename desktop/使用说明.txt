绷铁遗器一键分解 v1.5.2 测试版

Windows 10/11 64 位；游戏客户区 1920×1080、简体中文、PC 键鼠模式。

1. 关闭旧版，打开新 EXE，确认管理员授权。游戏无需重新登录。
2. 游戏停在主界面或遗器背包，点击“开始筛选并标记”。
3. 未满级平均满级潜力低于 80：标记弃置；已锁定低分件先解锁，再核验并标记。达到 80 保留，+15 跳过。
4. 已装备、状态不明或不能可靠评分的跳过，并显示原因。分解由你在游戏内确认。

“仅看评分”不会解锁或标记。自动操作时保持游戏前台，F8 或“停止”结束。进度显示本次已标记数量，明细支持当前分、平均潜力、理论上限排序。

内置 59 张女性角色官网立绘。侧栏“角色背景”可搜索选图、调节清晰度；人物旁的按钮可以换一张，每次打开也会更换。图片和识别模型已内置，无需 Python 或 Node。

强化为测试功能，完整读取后每次 +3，未满级平均潜力 80，满级当前分 80。仅允许经验材料及未锁定、未装备的四星及以下遗器，禁止吞五星。

本版通过后台评分、执行函数和界面测试；实际游戏解锁、标记和强化完整流程仍未完成端到端验证，继续作为测试版。

界面需要 Microsoft WebView2 Runtime。截图与背包只在本机处理。
