绷铁遗器一键分解 v1.5.0 测试版

Windows 10/11 64 位；游戏客户区 1920×1080、简体中文、PC 键鼠模式。

1. 关闭旧版工具，打开新 EXE，确认管理员授权。游戏无需退出或重新登录。
2. 游戏停在主界面或遗器背包，选择“低分弃置”，直接点“开始标记”。工具读取当前画面、评分并标记低分遗器。
3. “读取当前背包”只读取和评分。“仅预览”也不修改遗器。首次可以用预览核对当前界面。
4. 自动操作期间保持游戏前台，F8 或“停止”结束。结束后自行检查弃置列表并确认分解。

评分明细默认当前分从高到低。点击“当前分”“平均潜力”“理论上限”排序，再点同一项切换升序。

只评估已收录五星角色。默认满级当前分 ≥75；胚子平均满级潜力 ≥70 且上限 ≥85，可在设置修改。
已锁定、已装备、已弃置和保护状态不明的遗器不会自动标记；无法可靠识别的属性会跳过。隐藏小数按可能范围处理，仍可能达标的遗器保留。
中断或部分识别时会显示“部分背包”；再次开始会核验当前游戏，不要求重登。

强化为测试功能：完成本次完整读取后可处理高潜力胚子，每次 +3，未满级平均潜力 ≥80 继续，满级当前分 ≥80 保留。低分仅标弃置。允许经验材料和四星及以下遗器，禁止吞五星。
强化尚未完成真实游戏全流程验证，材料和等级不明确会停止。本次优先修复直接标记、识别、停止和评分排序。

已通过既有游戏画面的只读识别，以及后台界面、执行函数和服务交互测试；实际游戏遍历、弃置点击及强化全流程仍未完成端到端实测。本包继续作为测试版。

无需 Python 或 Node，识别模型已内置。界面使用微软 WebView2 Runtime。游戏截图与背包只在本机处理。
数据目录：%LOCALAPPDATA%\HSRRelicManager\data
任务截图和记录在 marker-runs 子目录。
